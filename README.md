# ahua Personal Site

A personal website memento adapted from a public classmate site template with
permission. The site owner information and homepage photographs have been
replaced for private use.

## Pages

- `index.html` - homepage
- `quote.html` - favourite quotations
- `project.html` - future project ideas
- `about.html` - personal introduction and contact

## Run locally

```powershell
python -m http.server 8000
```

Then open `http://127.0.0.1:8000`.
